# Practice Translator Skill

A Claude Code skill designed to help creatives, artists, performers, and practitioners explain their work clearly without losing its depth, nuance, or character.

## Why this exists

Many creative practices are difficult to describe. When trying to explain them to funders, collaborators, audiences, or institutions, the language can become either too vague, too academic, or overly polished.

This skill helps translate those practices into clear, audience-appropriate language while preserving the original voice and intent.

## Typical Uses

- Artist statements
- Workshop descriptions
- Funding applications
- Website copy
- Interview transcripts
- Rehearsal notes
- Process reflections

## Project Files

- `CLAUDE.md` – instructions and guiding principles
- `SKILL.md` – skill definition and workflow
- `trigger-test.md` – test prompts used during development

## Principles

- Use British English
- Preserve the practitioner's voice
- Avoid generic marketing language
- Avoid unnecessary jargon
- Prioritise clarity over complexity
- Highlight transformation and impact where relevant
